The pieces a case study is built from

The template page is one arrangement of these. Every project needs a different arrangement — a materials project leans on image grids, a software project on the iteration rows. Compose each chapter from whichever of these earn their place, and delete the rest rather than filling them.

Video or interaction

Development  ·  Delivery

For anything that only makes sense in motion — a mechanism, a sound, a screen flow. Give it a poster frame and never autoplay with sound.

Rhythm
Never two of the same block in a row. Alternate text-heavy and image-heavy so the page breathes, and let one image per chapter be markedly bigger than the rest.
Measure
Body text stops at 680px however wide the page gets. Images may run to the full content column, or break out to the page margin for a deliberate full-bleed moment.
Captions
Every image earns a caption that says something the photograph doesn't. If you can't write one, the image probably isn't needed.
